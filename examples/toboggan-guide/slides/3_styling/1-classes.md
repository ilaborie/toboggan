# Layout classes

Set `classes` in frontmatter to change a slide's layout:

| Class | Effect |
|---|---|
| `no_title` | Hide the auto-generated title bar |
| `wide` | Use 95% of the viewport width |
| `center` | Vertically + horizontally center content |
| `cover` | Cover/title styling |
| `spread-steps` | Distribute steps evenly down the slide |
| `step-line-through` | Strike out earlier steps as you advance |
