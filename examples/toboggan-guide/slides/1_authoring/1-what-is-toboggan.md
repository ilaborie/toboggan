# What is Toboggan?

A presentation system written in Rust: **Markdown decks with live terminals**.

<!-- pause -->

You write slides as plain **Markdown**, compile them with `toboggan-cli`, and serve them with `toboggan-server` — then present from a browser, a terminal, or any synced client.

<!-- pause -->

### Why it's different

|  |  |
| --- | --- |
| 🖥️ **Live terminals** | Embed real PTYs in a slide — demo code for real |
| 🔄 **Multi-client sync** | Presenter + audience stay on the same slide |
| 📦 **One source, many outputs** | TOML, JSON, YAML, static HTML, Typst/PDF |
| 🎨 **Plain CSS styling** | No bespoke DSL — just frontmatter and stylesheets |

<!-- notes -->

This guide is itself a Toboggan deck — everything you see is produced by the same tools it documents.
